Lalabella

Card Print

How to use: Click a card, then paste (Ctrl+V) a message copied from WhatsApp, or an image copied from Snipping Tool — both text and an image can go on the same card. Arabic text switches to right-to-left automatically. Long messages shrink to fit. Use the 🖼️ button on a card to browse for an image file instead of pasting.
